# Computational Geometry and Sensor Data Analysis

Programming tasks completed as part of the PWR Racing Team recruitment process.

The project covers geometric algorithms implemented in C++ and sensor data analysis and visualization in Python.

## Task 1 – Geometric Data Processing

- **Point deduplication:** Grouping spatially close points using Disjoint Set Union (Union-Find).
- **Convex hull:** Computing the convex hull of deduplicated points using Andrew's monotone chain algorithm.
- **Visualization:** Displaying input points, deduplicated points, and the resulting convex hull.

## Task 2 – Sensor Data Analysis

- Processing and analyzing sensor measurements.
- Visualizing measurement distributions with Python.
- Comparing observations across different sensors to identify patterns and discrepancies.
